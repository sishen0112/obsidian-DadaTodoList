# 截图目录

README「📸 界面预览」引用的截图统一放在本目录，文件名对应关系：

| 文件名 | 内容 |
|---|---|
| `week-view.png` | 周视图（七天时间轴） |
| `month-view.png` | 月视图（农历 / 节假日） |
| `agenda.png` | 日程视图 |
| `checklists.png` | 清单视图 |
| `list-view.png` | 列表视图 |
| `editor.png` | 任务编辑弹窗 |

建议：PNG 格式、宽度 ≥ 1200px；截图前把无关侧栏收起，保持画面干净。不需要的页面可从 README 中整段删除对应 `<p align="center">` 块。

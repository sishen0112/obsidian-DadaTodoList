- 任务 = 每日笔记 / 收件箱 / 清单文件里的 `- [ ]` 复选框，没有任何私有数据库；

- 不联网、无账号、无遥测，与 iCloud / Syncthing / Git 等任何同步方案和平共处。

## 二、解决什么问题（痛点话术）

**给已经在 Obsidian 里管待办的人**：
- 待办散落在日记和各处笔记里，回顾全靠搜索和翻文件；
- 只有干巴巴的列表，看不到「哪天该做什么」「这周负载如何」；
- 想要日历/时间轴，要么装多个插件拼凑，要么把任务搬进第三方服务。

**给还没用 Obsidian 管过待办的人**：
- 不想再注册第 N 个待办 App，数据被锁在别人服务器上；
- 想要一个「笔记和待办长在一起」的系统：开会记的笔记里顺手 `- [ ]`，就能进任务面板；
- 希望数据永远可迁移、可读、可备份。

**一句核心卖点**：*你写过的每一行待办，都会聚合成日历、时间轴、日程和清单——数据一行都不用搬。*

## 三、目标用户画像

1. **Obsidian 老用户 + 待办需求**：已用日记/每日笔记，苦于任务管理不成体系；
2. **效率工具爱好者**：用过上手 App（滴答/TeuxDeux/Todoist），想要数据自主权；
3. **职场项目参与者**：需要时间轴、任务拆解、多项目并行管理；
4. **备考/自学者**：长周期任务（考证、网课）需要章节化清单与进度感；
5. **PMO / 中层管理者**：多项目、多阶段、跨部门任务跟踪。

## 四、六种视图详解（功能 × 演示建议）

### 1. 日视图
- 内容：当天一列时间轴（07:00–24:00）+ 凌晨列表（00:00–07:00）+ 全天任务；
- 亮点：双击时间轴空白处可**在落点时刻直接新建任务**；
- 演示建议：用 demo 库 9/26（晨跑✅、每周复盘、采购、修台灯、火锅、阅读——内容最丰富的一天）。

### 2. 周视图
- 内容：七天并排，每小时一格（时间轴高度自适应窗口宽度）；
- 亮点：同一时段任务**自动泳道并排**，互不遮挡；表头显示农历、节气、节日、法定节假日（休/班）；
- 演示建议：跨天**拖拽改期**（把任务从周一拖到周三）；拖动任务块**上下边缘手柄**调整开始/结束时间。

### 3. 月视图
- 内容：整月日历格，每格显示任务数与任务块，格内含农历日、节气/节日标签、休/班徽标；
- 亮点：中文用户差异化卖点（国外同类插件没有的农历体系，数据来自 lunar-javascript）；
- 演示建议：翻到 9 月看「官网改版上线」的高光日；可在设置关闭农历只显示公历（0.2.0 新增开关）。

### 4. 日程视图
- 内容：按日期纵向滚动的议程，分组为「已延期 → 未来 7 天 → 更远」；
- 亮点：一键「回到今天」；
- 演示建议：配合过期任务多的场景，展示拖延可见化。

### 5. 清单视图
- 内容：左侧清单列表（带总数/完成进度），右侧按 `###` 标题分组展示任务；
- 亮点：列表/分栏两种布局；**分组间拖拽移动任务**；每组标题旁 + 按钮直接新增；
- 演示建议：用「智慧后勤平台PMO」（七阶段、33 项）讲项目管理；用「软考系统分析师」（16 章、49 项）讲长周期备考。

### 6. 列表视图
- 内容：全部任务池，左侧筛选（日期/标签/清单/状态），支持卡片模式；
- 亮点：多维筛选组合；「已办」分组可折叠；
- 演示建议：筛选 #工作 标签 + 状态=待办，展示工作场景专注模式。

## 五、任务语法速查（视频演示必备）

任务写在笔记正文里，一行一个复选框：

```markdown
- [ ] 09:30 站会 #工作                      ← 单时间任务
- [ ] 09:30-11:30 需求评审 #工作 ⏫          ← 时间段 + 优先级
- [ ] 预约牙医                              ← 无时间 = 全天（在日记里）或无日期（在收件箱）
- [x] 复盘 #生活 ✅ 2026-09-26              ← 已完成（✅ 后为完成日期）
- [-] 看直播带货 #生活                      ← 已取消
    - [ ] 子任务（缩进即子任务，层级不限）
    - [x] 已完成的子任务
    - 这一行是描述：缩进的普通文本会作为任务的描述行展示
- [ ] 每周复盘 🔁 每周六                     ← 循环任务（标记备注）
- [ ] 买礼物 [礼物链接](https://example.com) ← 内联链接
- [ ] 到点不想被打扰的任务 🔕                ← 静音标记（展示位自动隐藏）
```

优先级符号：`⏫`（高）`🔺` `🔼` `🔽`（低）。

**任务数据存在哪里（三种位置）**：
| 位置 | 内容 | 配置 |
|---|---|---|
| 每日笔记 | 有日期的任务 | 完全跟随核心「日记」插件配置（文件夹+日期格式） |
| 收件箱文件 | 无日期任务 | 默认根目录 `DadaTodoList.md`，可改；换路径会主动询问迁移旧任务 |
| 清单文件 | 清单任务 | frontmatter `tags` 含 `todoList`（可配多个标记）的笔记，全库识别 |

## 六、清单系统（重点功能，单独可出一期）

- **成为清单**：任意笔记 frontmatter `tags` 加 `todoList` 即可，不限目录；
- **分组**：`###` 三级标题即分组名，标题前的任务归入「未分组」；
- **子任务**：缩进复选框，层级不限；
- **操作**：分组间拖拽移动、分组旁 + 按钮新增、点任务打开编辑弹窗、Ctrl/⌘+点击跳转源文件；
- **进度**：侧栏实时显示每份清单的总数与完成数；
- **布局**：列表 / 分栏两种。

**演示库中四份清单的分工（讲不同故事）**：
1. 智慧后勤平台PMO —— 项目阶段流（立项→招采→需求→设计→测试→上线→结项），进度 ~27%；
2. 采购审查-数据中心扩容 —— 审查阶段流，含合规细节（资质核验、围标排查）；
3. 合同法律审查 —— 按部门分组，任务=合同标题；
4. 软考系统分析师 —— 按章节分组，49 项任务的长周期备考。

| 功能 | 操作 | 说明 |
|---|---|---|
| 拖拽改期 | 月/周视图间拖任务 | 无日期任务拖入日期默认全天；定时任务保留原时刻 |

## 九、隐私与数据访问（审核披露口径，对外统一说法）

- **文件枚举**：仅扫描 Markdown 文件路径与 frontmatter 用于发现日记/清单；正文只读命中文件（限加载范围内日记、收件箱、清单）；
- **localStorage**：只存界面偏好（视图/筛选/引导状态），不含笔记内容、绝不联网；刻意不写 `data.json` 以免触发云盘同步；
- **网络**：无任何网络请求、无遥测。

## 十四、FAQ（评论区高频问题预演）

**Q：卸载插件会丢任务吗？**
不会。任务就是笔记里的普通复选框，插件只是「读取+聚合」。

**Q：支持手机吗？**
支持（桌面/移动同一套功能），数据跟随你的同步方案。

**Q：和 Tasks 插件什么区别？**
Tasks 偏通用查询语法；达达清单自带六视图（尤其时间轴与农历月视图）、拖拽改期、清单分组，开箱即用不需要写查询语句。

**Q：任务能循环/重复吗？**
支持 `🔁` 循环标记备注；完整的自动重排循环在路线图中。

**Q：会收费吗？**
不会，MIT 开源。可以自愿赞赏（仓库 README 有二维码）。

**Q：日记插件没开会怎样？**
有日期任务不可读写，面板顶部会出现提醒条引导开启；收件箱与清单不受影响。
